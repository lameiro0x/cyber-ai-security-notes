# Intro a RAG Applications

Un RAG-power chatbot es un asistente de chat que utiliza esta arquitectura para responder a preguntas basadas en información específica y confiable. Sus principales características son:

- **Contexto actualizado:** Accede a datos en tiempo real o documentos actualizados, superando las limitaciones de conocimiento de la IA tradicional.
- **Reducción de Alucinaciones:** Al "leer" documentos antes de contestar, el bot reduce drásticamente las invenciones o respuestas falsas.
- **Citas y Fuentes:** Añade citas que respaldan sus afirmaciones, aumentando la fiabilidad. 

> Ahora es muy facil hacer pequenos proof of concept (POC) de IA pero pasarlos a produccion es muy complicado 
> 
> AI reliability es un problema actualmente, evitar que estos programas que dependen de IAs con OpenAI, Claude, o Gemini hagan cosas, tener una frecuencia de errores baja

# Montar RAG Chatbot

Importamos todo lo necesario para que los warning se vean clean 

```python
import warnings
warnings.filterwarnings("ignore")
%env TOKENIZERS_PARALLELISM=true
```

Y ademas tambien lo necesario para montar la app y funciones que nos ayuden

```python
from openai import OpenAI

from helper import RAGChatWidget, SimpleVectorDB
```

Ahora vamos a montar el Chatbot

Usamos este mensaje para despues montarlo, este le da el rol y el contexto, que basicamente es del servicio al cliente de una pizzeria

```python
system_message = """You are a customer support chatbot for Alfredo's Pizza Cafe. Your responses should be based solely on the provided information.

Here are your instructions:

### Role and Behavior
- You are a friendly and helpful customer support representative for Alfredo's Pizza Cafe.
- Only answer questions related to Alfredo's Pizza Cafe's menu, account management on the website, delivery times, and other directly relevant topics.
- Do not discuss other pizza chains or restaurants.
- Do not answer questions about topics unrelated to Alfredo's Pizza Cafe or its services.

### Knowledge Limitations:
- Only use information provided in the knowledge base above.
- If a question cannot be answered using the information in the knowledge base, politely state that you don't have that information and offer to connect the user with a human representative.
- Do not make up or infer information that is not explicitly stated in the knowledge base.
"""
```


Montamos el LLM:

```python
# Setup an OpenAI client
client = OpenAI()
```

Y tambine montamos la base de datos don estan los documentos ya puestos previamente, donde cogera la info el chatbot:


```python
vector_db = SimpleVectorDB.from_files("shared_data/")
```

Y ahora creamos e iniciamos el chatbot


```python
# Setup RAG chabot
rag_chatbot = RAGChatWidget(
    client=client,
    system_message=system_message,
    vector_db=vector_db,
)
```


```python
rag_chatbot.display()
```
