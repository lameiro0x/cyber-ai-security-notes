**TFRecord:** Binary format and easier to read for computers, making it ideal for efficient training.

#### Joining Tables and Query Optimization

Combinaremos dos tables, para filtrar la informacion que unicamente necesitamos para optimizarlo todo,

Cogemeremos las preguntas de `posts_questions` y las guardaremos como `input_text` (columna 1) y las respuestas de `posts_answers` y las guardaremos como `output_text` (columna 2).

Las unimos a traves de una ID que comparten

Para asegurarnos que son preguntas sobre python y tienen respuestas las cogeremos de `2020-01-01` en adelante con limite en 10000

Vamos a hacer la query:

```python
QUERY = """
SELECT
    CONCAT(q.title, q.body) as input_text,
    a.body AS output_text
FROM
    `bigquery-public-data.stackoverflow.posts_questions` q
JOIN
    `bigquery-public-data.stackoverflow.posts_answers` a
ON
    q.accepted_answer_id = a.id
WHERE
    q.accepted_answer_id IS NOT NULL AND
    REGEXP_CONTAINS(q.tags, "python") AND
    a.creation_date >= "2020-01-01"
LIMIT
    10000
"""
```

```python
query_job = bq_client.query(QUERY)
```

```python
### this may take some seconds to run
stack_overflow_df = query_job.result()\
                        .to_arrow()\
                        .to_pandas()

stack_overflow_df.head(2)
```

### Anadiendo instrucciones 

Con las instrucciones le damos algo de contexto al modelo y no le pasamos solo la informacion, asi sabra que hacer y no solo almacena la info y hace lo que le da la gan. 

En este caso le diremos que conteste a las preguntas de Stackoverflow

```python
INSTRUCTION_TEMPLATE = f"""\
Please answer the following Stackoverflow question on Python. \
Answer it like you are a developer answering Stackoverflow questions.

Stackoverflow question:
"""
```

Combinaremos en una nueva columna la instruccion y las preguntas


```python
stack_overflow_df['input_text_instruct'] = INSTRUCTION_TEMPLATE + ' '\
    + stack_overflow_df['input_text']
```

### Datasets para tunear
