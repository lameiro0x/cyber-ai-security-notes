## Preparacion

Para orquestrar y automatizar el workflow usaremos  [Kubeflow Pipelines](https://www.kubeflow.org/docs/components/pipelines/v2/)

Los imports son:

```python
from kfp import dsl
from kfp import compiler

# Ignore FutureWarnings in kfp
import warnings
warnings.filterwarnings("ignore", 
                        category=FutureWarning, 
                        module='kfp.*')
```

## Kubeflow Pipelines

Se componen de dos piezas claves, componentes y pipelines
Pipeline componentes son como sets de codigo autocontenidos para ejecutar varios pasos en en el ML workflow. El primer paso puede ser pre-procesar datosm y el segundo entrenar el modelo

### Ejemplo simple de Pipeline

#### Montar la pipeline

Como la metemos el decorator `@dsl.component` la funcion no devolvera una string, delvolvera un objeto `PipelineTask`

> Este codigo correra en un entorno contenerizado, (dentro de un contendor)

```python
### Simple example: component 1
@dsl.component
def say_hello(name: str) -> str:
    hello_text = f'Hello, {name}!'
    
    return hello_text
```

Vamos a crear otro que dependa el output del anterior componente, creando una cadena de dependencia

```python
### Simple example: component 2
@dsl.component
def how_are_you(hello_text: str) -> str:
    
    how_are_you = f"{hello_text}. How are you?"
    
    return how_are_you
```

Ahora vamos a ejecutar un workflow, vamos a montar la pipeline: diciendo el orden en el que queremos ejecutar las cosas, fijarse como se pasan los argumentos de las funciones

> Fijarse tambien en el decorator de pipeline

```python
### Simple example: pipeline
@dsl.pipeline
def hello_pipeline(recipient: str) -> str:
    
    # notice, just recipient and not recipient.output
    hello_task = say_hello(name=recipient)
    
    # notice .output
    how_task = how_are_you(hello_text=hello_task.output)
    
    # notice .output
    return how_task.output 
```

#### Implementar la pipeline

Vamos a compilar la pipeline en un archivo ejecutable, para eso usaremos yaml

```python
compiler.Compiler().compile(hello_pipeline, 'pipeline.yaml')
```

Ahora definimos los argumentos en ese archivo:

```python
pipeline_arguments = {
    "recipient": "World!",
}
```

Para ejecutarlo en nuestro propio entorno podemos usar el siguiente codigo:

```python
### import `PipelineJob` 
from google.cloud.aiplatform import PipelineJob

job = PipelineJob(
        ### path of the yaml file to execute
        template_path="pipeline.yaml",
        ### name of the pipeline
        display_name=f"deep_learning_ai_pipeline",
        ### pipeline arguments (inputs)
        ### {"recipient": "World!"} for this example
        parameter_values=pipeline_arguments,
        ### region of execution
        location="us-central1",
        ### root is where temporary files are being 
        ### stored by the execution engine
        pipeline_root="./",
)

### submit for execution
job.submit()

### check to see the status of the job
job.state
```

### Ejemplo de la vida real de un Pipeline

#### Automatizacion y orquestracion de el Tuneo supervisado de una pipeline

> Aqui vamos a preparar el versionado y tuneo y entrenamiento de.un modelo

Esto nos permitira poder reusar pipelines en otros casos:

Vamos a usar los siguientes dos archivos

```python
### these are the same 
### jsonl files from the previous lab

### time stamps have been removed so that 
### the files are consistent for all learners
TRAINING_DATA_URI = "./tune_data_stack_overflow_python_qa.jsonl" 
EVAUATION_DATA_URI = "./tune_eval_data_stack_overflow_python_qa.jsonl"  
```

Y tambien vamos a registrar donde vamos aguardar lo generado

```python
### path to the pipeline file to reuse
### the file is provided in your workspace as well
template_path = 'https://us-kfp.pkg.dev/ml-pipeline/\
large-language-model-pipelines/tune-large-model/v2.0.0'
```

Vamos a preparar el versionado para el modelo que vamos a entrenar

```python
import datetime
```

```python
date = datetime.datetime.now().strftime("%H:%d:%m:%Y")
```

```python
MODEL_NAME = f"deep-learning-ai-model-{date}"
```

Ahora vamos a poner el numeros de pasos de entrenamiento y la frecuencia con la quie se va a evaluar el modelo

```python
TRAINING_STEPS = 200
EVALUATION_INTERVAL = 20
```

Cargamos el ID, las creedenciales y region del proyecto:

```python
REGION = "us-central1"
```

 Y definimos los argumentos, el input que va en la pipeline:

```python
pipeline_arguments = {
    "model_display_name": MODEL_NAME,
    "location": REGION,
    "large_model_reference": "text-bison@001",
    "project": PROJECT_ID,
    "train_steps": TRAINING_STEPS,
    "dataset_uri": TRAINING_DATA_URI,
    "evaluation_interval": EVALUATION_INTERVAL,
    "evaluation_data_uri": EVAUATION_DATA_URI,
}
```

Para ejecutarlo en nuestro propio entorno podemos usar el siguiente codigo:

```Python
pipeline_root "./"

job = PipelineJob(
        ### path of the yaml file to execute
        template_path=template_path,
        ### name of the pipeline
        display_name=f"deep_learning_ai_pipeline-{date}",
        ### pipeline arguments (inputs)
        parameter_values=pipeline_arguments,
        ### region of execution
        location=REGION,
        ### root is where temporary files are being 
        ### stored by the execution engine
        pipeline_root=pipeline_root,
        ### enable_caching=True will save the outputs 
        ### of components for re-use, and will only re-run those
        ### components for which the code or data has changed.
        enable_caching=True,
)

### submit for execution
job.submit()

### check to see the status of the job
job.state
```
