## Alucionaciones 

A Hallucination is an LLM’s response that is either inaccurate or irrelevant

![pasted_image_20260504234513.png](<../images/pasted_image_20260504234513.png>)

How to measure hallucinations?
- Prompt-response relevance: Measure the similarity between response and prompt.

### Semantic similarity vs relevance

Esto es un ejemplo de que lo de abajo puede serr una respuesta considerada no alucionacion porque para que semanticamente son similares pero lo que responde es irrelevante

![pasted_image_20260504235056.png](<../images/pasted_image_20260504235056.png>)

Y este ejemplo siguiente puede detectarlo como alucionacion a pesar de que este bien porque semanticamente no son nada similares el prompt y la respuesta

![pasted_image_20260504235250.png](<../images/pasted_image_20260504235250.png>)

Para solucionar esto a la pregutna anterior How to measure hallucinations? tambien debemos responder 
- Response self-similarity: Compare the similarity between multiple responses to the same prompt.
