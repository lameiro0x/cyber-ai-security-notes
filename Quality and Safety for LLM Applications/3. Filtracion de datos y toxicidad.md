Ahora para la filtracion de datos podemos hacer una lista con el tipo de entidades que queremos reconocer

```python
leakage_entities = ["person", "product","organization"]
```

Y ahora crear una funcion que use la lista anteroirr

```python
from whylogs.experimental.core.udf_schema import register_dataset_udf
```

```python
@register_dataset_udf(["prompt"],"prompt.entity_leakage")
def entity_leakage(text):
    entity_counts = []
    for _, row in text.iterrows():
        entity_counts.append(
            next((entity["label"] for entity in \
                entity_model.predict(row["prompt"]) if\
                entity["label"] in leakage_entities and \
                entity["score"] > 0.25), None
            )
        )
    return entity_counts
```

Podemos ver las entidades en los chats con filtracion de datos sacados por la funcion asi:

```python
entity_leakage(chats.head(5))
```

![pasted_image_20260505110124.png](<../images/pasted_image_20260505110124.png>)

Podemos hacer lo mismo para respuestas, cambiando todas las apariciones de `prompt` por `response`:

```python
@register_dataset_udf(["response"],"response.entity_leakage")
def entity_leakage(text):
    entity_counts = []
    for _, row in text.iterrows():
        entity_counts.append(
            next((entity["label"] for entity in \
                entity_model.predict(row["response"]) if\
                entity["label"] in leakage_entities and \
                entity["score"] > 0.25), None
            )
        )
    return entity_counts
```

## Toxicity

Hacemos los imports y cargamos el modelo necesario:

```python
from transformers import pipeline
```

```python
toxigen_hatebert = pipeline("text-classification", 
                            model="tomh/toxigen_hatebert", 
                            tokenizer="bert-base-cased")
```

Podemos probarlo asi:

```python
toxigen_hatebert(["Something non-toxic",
                  "A benign sentence, despite mentioning women."])
```

![pasted_image_20260505110830.png](<../images/pasted_image_20260505110830.png>)

Ahora podemos crear una funcion para utilizarlo:

> Podemos hacer lo mismo para respuestas, cambiando todas las apariciones de `prompt` por `response` pero no lo vemos aqui

```python
@register_dataset_udf(["prompt"],"prompt.implicit_toxicity")
def implicit_toxicity(text):
    return [int(result["label"][-1]) for result in 
            toxigen_hatebert(text["prompt"].to_list())]
```

Y ahora podemos ver los ejemplos con mas toxicidad:

